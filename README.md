## Project Scope

Expense Tracker is a Python-based application used to record, manage, and analyze daily expenses. The project stores expense data using CSV file handling.

## Features

- Add new expenses
- View all expenses
- Search expenses by category
- Calculate total expenses
- Store data permanently using CSV
- Exception handling for invalid inputs

## Technologies Used

- Python
- CSV File Handling
- Exception Handling

## Project Files

- main.py - Main application code
- expenses.csv - Stores expense records
- screenshots - Output screenshots

## How to Run

2. Open the project folder in terminal
